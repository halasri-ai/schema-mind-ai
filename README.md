# SchemaMind AI

AI-powered enterprise Excel header mapping platform using semantic matching and Azure OpenAI.

## Features

- AI-powered header mapping
- Multi-schema support
- Mapping memory
- Ambiguity resolution
- Confidence scoring
- Streamlit UI
- SQLite logging

## Tech Stack

- Python
- Streamlit
- Azure OpenAI
- Pandas
- SQLite

## Run Project

```bash
streamlit run streamlit_app/app.py
```
